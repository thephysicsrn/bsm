Como Conectar o Raspberry Pi ao Mac

          


          

            

              
1

              

                Ligue o botão físico nos pinos do Raspberry Pi:
                
    
                  
  • Um terminal no Pino Físico 32 (BOARD 32 / GPIO BCM 12)
    • 
                  
  • Outro terminal no Pino Físico 34 ou 30 (GND)
    • 
                

              

            


            

              
2

              

                Baixe o arquivo diretamente no Raspberry Pi (via rede local):
                

                  curl -O http://172.30.230.186:8765/raspberry_botao.py
                  
                

                
                  Execute no terminal do Raspberry Pi para baixar o script pronto do Mac.
                
              

            


            

              
3

              

                Execute no terminal do Raspberry Pi:
                

                  python3 raspberry_botao.py --server http://172.30.230.186:8765 --pin 32
                  
                

                
                  Dica: Para testar sem a placa física, adicione --interactive ao final.
